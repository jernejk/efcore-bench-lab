What the optimizer had to do

The predicate is not index-friendly. SQL Server cannot seek into `LOWER(Customer + Region + Product + SalesPerson) LIKE '%road%'`, so it reads broadly, joins data, computes text, filters, and sorts before it can apply page boundaries.

WHERE LOWER([c].[Name] + N' ' + [c].[Region] + N' ' + [p].[Name] + N' ' + [s].[SalesPerson]) LIKE N'%road%'
